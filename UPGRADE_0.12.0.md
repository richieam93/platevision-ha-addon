# Upgrade auf PlateVision 0.12.0

Die neue Personenbild-Galerie befindet sich unter `/people/gallery`.

- Neuinstallationen verwenden 10 Tage Bildaufbewahrung und automatisches Cleanup.
- Bestehende, ausdrücklich gespeicherte Aufbewahrungswerte bleiben erhalten.
- Stelle in **Einstellungen → Personenanalyse** oder direkt in der Galerie den gewünschten Wert ein.
- `0` bedeutet unbegrenzte Bildaufbewahrung.
- Wird die Frist verkürzt und Cleanup ausgeführt, können gelöschte Bilder nicht wiederhergestellt werden.
- Die statistischen Personenereignisse bleiben beim reinen Bild-Cleanup erhalten.

- Die Personen-Historie besitzt neu eine eigene Obergrenze von standardmässig 20’000 Ereignissen.
