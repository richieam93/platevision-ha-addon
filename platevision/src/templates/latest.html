Home Assistant Integration

Die unten aufgeführten API-Pfade gelten für PlateVision. Innerhalb der Home-Assistant-Seitenleiste sind Ingress-Session-Adressen nicht für dauerhaft laufende REST-Sensoren geeignet. Für eine externe Integration ist ein ausdrücklich freigegebener und zusätzlich abgesicherter Direktport erforderlich.

API Endpunkte
GET /api/latest
GET /api/latest/plate
GET /api/latest/plate/image
GET /api/latest/vehicle/image
Home Assistant configuration.yaml 
{% raw %}# PlateVision Integration
# Nur bei ausdruecklich freigegebenem Direktport 8087 und zusaetzlichem Zugriffsschutz

# REST Sensor für Kennzeichen-Text
sensor:
  - platform: rest
    name: "Letztes Kennzeichen"
    resource: http://<PLATEVISION_IP>:8087/api/latest/plate
    value_template: "{{ value_json.plate_text }}"
    scan_interval: 10
    json_attributes:
      - confidence
      - vehicle_type
      - vehicle_color
      - timestamp

  - platform: rest
    name: "Kennzeichen Details"
    resource: http://<PLATEVISION_IP>:8087/api/latest
    value_template: "{{ value_json.plate_text }}"
    scan_interval: 10
    json_attributes:
      - confidence
      - vehicle_type
      - vehicle_color
      - timestamp
      - source

# Kamera für Kennzeichen-Bild
camera:
  - platform: generic
    name: "Letztes Kennzeichen Bild"
    still_image_url: http://<PLATEVISION_IP>:8087/api/latest/plate/image
    verify_ssl: false

  - platform: generic
    name: "Letztes Fahrzeug Bild"
    still_image_url: http://<PLATEVISION_IP>:8087/api/latest/vehicle/image
    verify_ssl: false

  # Optional: MJPEG Stream
  - platform: mjpeg
    name: "PlateVision Live"
    mjpeg_url: http://<PLATEVISION_IP>:8087/api/stream/feed
    verify_ssl: false{% endraw %}
Das YAML-Beispiel benötigt einen bewusst freigegebenen Direktport (z. B. 8087). Ersetzen Sie <PLATEVISION_IP> durch die IP-Adresse Ihres Home-Assistant-Rechners. Der Direktport ist ab Version 0.13.0 aus Sicherheitsgründen standardmäßig ausgeschaltet; die Ingress-Session-Adresse in der Browserzeile darf hier nicht verwendet werden.
