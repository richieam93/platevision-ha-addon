# PlateVision Beispiele für Home Assistant

Diese Beispiele passen zu PlateVision **0.8.28**.

Passe in allen Dateien zuerst die Basis-URL an:

```text
http://192.168.1.240:8087
```

Empfohlene Reihenfolge:

1. Inhalt aus `configuration.yaml` in deine Home-Assistant-Konfiguration übernehmen.
2. Home Assistant neu starten oder YAML neu laden.
3. Optional `automations.yaml`, `scripts.yaml` und die Lovelace-Karten übernehmen.
4. Die verfügbaren Entity-IDs stehen in `entity_ids.md`.
5. Eine Übersicht der aktuellen API-Endpunkte steht in `api_endpunkte.md`.

Die alten nicht mehr passenden Beispiel-Dateien wurden entfernt.
